发票的基本概念、底层逻辑和申领流程

发票是公司运营环节中不可缺少的一部分，也是公司缴税、纳税的凭证。本文将介绍发票的基本概念、发票有什么作用、发票的种类和区别，以及申请领购发票的具体流程。

发票是什么？​

发票是交易双方在购销商品、提供或接受服务等经营活动中开具的法定凭证，用于证明交易的真实性、合法性，并作为税务核算和财务收支的依据。

最早的发票出现在 19 世纪的英国，在工业革命之后，国际贸易变得频繁，欧美国家为规范商业交易和税收，开始推行统一格式的发票。新中国成立以前，民间买卖通常使用简单的收据或契约，缺乏统一规范。新中国建立后，才逐步引入苏联模式的发票管理制度。1993年，中国首次颁布《中华人民共和国发票管理办法》，标志发票管理全面法治化。2013年，一位读者在京东商城购买的是2本《中国梦》修订版，并选择了电子发票，这是中国大陆首张电子商务领域的电子发票。此后，电子发票兴起，推动无纸化进程。

发票的三大功能​

发票具有三大核心作用，分别是税务功能、财务功能和法律功能，具体说明如下。

  • 税务功能：
    • 企业凭发票申报增值税进项抵扣（专票），减少应纳税额。
    • 国家通过发票监管企业收入，防止偷税漏税。
  • 财务功能：
    • 企业记账依据（如成本、费用核算）。
    • 员工报销凭证（需发票佐证支出真实性）。
  • 法律功能：
    • 发生经济纠纷时，发票可作为法律证据。
    • 消费者维权依据（如商品质量问题需凭发票退换）。

发票的种类​

增值税专用发票（专票）​

适用对象：一般纳税人企业

核心作用：

  • 进项税抵扣：购买方凭票抵扣增值税（如企业采购原材料，可抵 13% 的进项税）。
  • 税务监管：发票信息联网税务系统，严格追踪交易链条。

特点：

  • 必须提供完整的购买方信息（名称、税号、地址电话、开户行及账号）。
  • 需通过税控系统开具，全国统一格式（2023年全面电子化）。

示例：

  • 某制造企业购买设备，供应商开具 13% 税率的增值税专用发票，买方可将税额从销项税中扣除。

增值税普通发票（普票）​

适用对象：所有纳税人（包括小规模纳税人）

核心作用：

  • 记账凭证：记录成本费用，但不可抵扣进项税（特殊情况除外，如农产品收购普票）。
  • 消费者报销：员工差旅、办公用品采购等需普票作为报销依据。

分类：

  • 纸质普票：传统机打发票，需加盖发票专用章。
  • 电子普票：OFD 或 PDF 格式，与纸质版同等效力（如微信支付后收到的电子发票）。

示例：

  • 小规模纳税人餐厅开具 1% 税率的增值税普通发票给个人顾客。

机动车销售统一发票​

适用场景：汽车、摩托车等机动车零售

特殊要求：

  • 必须注明车辆识别代码（车架号）、发动机号。
  • 购买方为个人时需填写身份证号，企业需填税号。

作用：

  • 上牌、购置税缴纳、保险购买的必备凭证。

定额发票​

适用场景：小额零星交易（如停车场、小吃店）

特点：

  • 固定面额（如10元、50元、100元），手撕即用，无需打印。
  • 逐渐被淘汰：2023年起多地停用，改为电子或机打发票。

风险提示：

  • 易被虚开，需查验发票章与商户名称是否一致。

行业专用发票​

常见类型包括：

  • 出租车发票：自动打印行程、金额，不可用于抵扣。
  • 火车票、飞机行程单：可作为差旅费进项抵扣（高铁票可抵 9% 进项税）。
  • 通行费电子发票：ETC 用户通过平台开具，可抵扣 1%-9% 进项税。

电子发票（含专票和普票）​

政策背景：2021年起全国推广增值税电子专票。

优势：

  • 无纸化：节省打印、存储成本。
  • 防伪性强：通过税务 UKey 加密，可在线查验真伪（登录全国增值税发票查验平台）。

注意事项：

  • 电子专票需保存 OFD 源文件，打印件无效。

关键区别对比表​

发票类型可否抵扣进项税适用纳税人形式典型场景
增值税专用发票✅一般纳税人电子/纸质企业间大宗采购
增值税普通发票❌（特殊除外）所有纳税人电子/纸质个人消费、小额交易
机动车销售发票✅（企业购车）机动车经销商纸质4S店购车

通行费电子发票✅（部分抵扣）所有纳税人电子ETC缴费、道路通行
火车票/机票✅（差旅用途）所有纳税人纸质/电子行程单员工出差交通费

增值税的底层逻辑​

专票 vs 普票​

对于初创企业，重点关注增值税专用发票（专票）和增值税普通发票（普票），两者的区别如下表所示。

对比项增值税专用发票增值税普通发票
进项税抵扣✅ 购买方可抵扣销项税❌ 一般不可抵扣（特殊行业除外）
开票主体仅限一般纳税人企业开具所有企业均可开具（含小规模纳税人）
信息要求需完整购买方信息（名称、税号、地址、银行账户）仅需购买方名称和税号（个人可不填税号）
税务监管强度全流程监控（开票、抵扣、申报）仅作为交易凭证，监管相对宽松

下面列举几个使用场景帮助大家加深理解：

  • 专票场景：
    • 企业采购生产设备（如工厂购买机床，需 13% 专票抵扣）。
    • B2B服务合作（如广告公司向客户开具 6% 专票）。
  • 普票场景：
    • 员工日常报销（如餐饮、打车费）。
    • 面向个人消费者销售（如网店向个人买家开票）。

增值税的运行机制​

从运行机制来讲，增值税是**“链条税”**，企业仅对商品/服务的增值部分纳税：

  • 销项税：企业销售商品时向客户收取的税款（如售价113元，含13元税）。
  • 进项税：企业采购时支付给供应商的税款（如进货价56.5元，含6.5元税）。
  • 实际缴税 = 销项税 - 进项税 = 13元 - 6.5元 = 6.5元。

因此，抵扣进项税的本质是避免重复征税，税负最终由消费者承担。

发票开具规则​

  • 小规模纳税人：
    • 默认只能开普票（税率 1% 或 3%），但可申请税务局代开专票（需预缴税款）。
    • 年销售额超 500 万元需强制转为一般纳税人。
  • 一般纳税人：
    • 可自开专票（税率 6% / 9% / 13%），但需确保进项发票足够，否则可能税负过高。

核心原则：专票是节税工具，但不可滥用；普票是合规底线，需严格审核。

通过精细化发票管理，企业可降低税负10%-30%，同时建立合规护城河。

发票申领流程​

目前税务改革正在朝着即时办结、方便办税的方向发展，许多地方都提供了网上申领渠道，让经办人足不出户就能申领发票。

首次申领发票需要同时满足以下条件：

  1. 经办人、法定代表人已进行实名信息采集和验证。
  2. 申请人有开具增值税发票的需求，主动申领发票。
  3. 申请人按规定办理税控设备发行等事项。

申请人首次申领发票需要完成发票票种核定、增值税专用发票最高开票限额审批、增值税税控系统专用设备初始发行、发票领用等工作。

下面介绍更加简便的网上申领发票的步骤（不同的地区申领流程会有差异，申请人需要时刻关注当地税务局发布的信息）。

  1. 登录电子税务局，进入发票管理页面，点击发票领用，填写相关信息。另外，申请人可以根据需要在前往税务大厅领取、邮政快递寄送和回单柜领取三种模式中选择一种取票方式。
  2. 选好领取方式之后，点击“新增”，即可选择申领发票的数量。
  3. 如果申请选择邮政快递取票，还需要填写收件地址。点击“使用其他地址”，即可添加新地址。

申请人需要注意的是，如果申领的是增值税专用发票或增值税普通发票，还需要在“增值税发票税控开票软件”读取发票信息后，才可以开具发票。

FAQs​

Q1：客户坚持要专票，但我是小规模纳税人怎么办？

  • 方案1：向税务局申请代开 3% 专票（需预缴税款）。
  • 方案2：若长期需求，评估转为一般纳税人的利弊（需健全财务核算能力）。

Q2：员工拿回的普票，如何判断能否入账？

  • 三要素校验：
    1. 发票抬头为公司全称+税号（个人消费除外）。
    2. 商品/服务名称与业务相关（如“办公用品”需附明细清单）。
    3. 金额合理（如出差餐费每人每天 ≤ 100元）。

Q3：为什么税务局严查“进销项不匹配”？

  • 典型风险：贸易企业进项是钢材（13%），销项却是服装（13%），逻辑矛盾。
  • 合规做法：保持进项与销项的商品/服务大类一致，保留物流单、合同佐证。

总结​

创业者需要对发票有清晰的认知 —— 发票管理是合规经营的生命线，需从第一笔交易开始规范，避免因历史惯性轻视其重要性（如用收据替代发票、漏开发票等）。在具体操作中，需要明确自身是一般纳税人还是小规模纳税人，从而决定开票策略。同时养成良好习惯，定期复盘，每月分析进项/销项占比，避免税负异常波动，有利于公司财务正常运作。
