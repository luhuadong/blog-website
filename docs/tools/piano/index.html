键盘映射

低音组 (C3-B3)

1 → C32 → D33 → E34 → F35 → G36 → A37 → B3
Q → C#3W → D#3R → F#3T → G#3Y → A#3

中音组 (C4-B4) - 中央C

A → C4S → D4D → E4F → F4G → G4H → A4J → B4
Z → C#4X → D#4C → F#4V → G#4B → A#4

高音组 (C5-B5)

[ → C5] → D5\ → E5; → F5' → G5Enter → A5Shift → B5
= → C#5- → D#50 → F#59 → G#58 → A#5

功能特点

  • 🎵 实时音频播放
  • ⌨️ 键盘快捷键支持
  • 🖱️ 鼠标点击演奏
  • 🎹 电子钢琴音色
  • 🎼 三组八度音域
  • 🎛️ 谐波合成技术
  • 📱 响应式设计

使用说明

  1. 点击钢琴键或使用键盘按键来演奏
  2. 按住按键可以持续播放音符
  3. 释放按键停止播放
  4. 支持同时演奏多个音符
