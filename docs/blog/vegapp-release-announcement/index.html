找素食 App 发布预告，聊聊项目进展和我的思考

2025年12月30日 · 阅读需 9 分钟
阿基米东
程序员、科技作者、环保主义者、创业者

2025年就要结束了，首先很抱歉，之前说年底会上线的我们的素食 App（小程序），但是很遗憾，因为各种原因，没能如期上线。现在的卡点是这个小程序涉及内容创作和分享功能，属于 UGC 平台，需要相关部门审核。反正就是挺烦人的，啥都要审核，每次都要审核好几天，审核不通过还要处理好才能再次提交审核。

这个项目从9月份开始启动，本来想着花三个月时间速战速决，现在看来是低估了难度啦！如果审核不通过，还是得想办法把 ICP 经营许可证办下了，估计又要花一两个月时间。现在国内的互联网环境真的越来越严格了，不容易啊！

最近做了些什么​

这段时间认认真真肝了两三个星期，总算把核心功能都实现完了，主要包括数据库设计、后台管理系统搭建、前端小程序开发，具体功能板块包括用户管理、商户管理、食谱管理、笔记管理。因为涉及 UGC（用户生成内容），所以还花了些时间研究并搭了一套简单的审核机制。

有时候不想写代码、不想调试，就会读几本素食、营养相关的书。毕竟要在素食行业创业，必须要让自己成为这个领域的专家，才能引领行业发展。

另外还提交了一次创投大赛申请，花了整整两天时间填资料、录视频。暂时还没有结果，不过这次经历也帮我梳理清楚了一些问题。

有时候会觉得挺奇怪的，因为现在投资人喜欢的项目是 AI、机器人方向。而我的本职工作其实也更适合做这些，但现在创业的项目却是做一个小众赛道 —— 素食。

打磨这个产品的过程中，有时候也会觉得尴尬，因为不知道这是不是大家想要的、需要的东西。不过，最近听播客听到有人分享：创业做产品的时候感到尴尬就对了，如果不尴尬，说明已经没有机会了。

今年真的经历了好多事情，这个过程虽然有点苦，但经历完之后，现在回想起来，还真有点不一样了，包括对世界的理解，对人性的洞察。 也对创业这件事情有了更深的理解，无论做什么行业、什么项目，都要对这个领域有足够的了解，甚至成为行业专家。

对了，我还发布了一个叫 HowToCookVegan 的开源项目，已经在 GitHub 开源，内容发布在我们公司的官网，大家感兴趣可以去看看。也欢迎大家参与进来，一起写好这份素食指南。

  • GitHub 地址：https://github.com/huggypig/HowToCookVegan
  • 在线阅读：https://huggypig.com/docs/

找素食小程序​

虽然我们正式版本没有上线，不过我们的 demo 上线了！大家可以扫码进去看看，虽然真实功能还没开放，但也有整体模块设计，可以先感受一下，给我们提点建议。

小程序目前的名字叫“抱抱猪找素食”，其中“抱抱猪”是我们公司的名字，“找素食”是我们为这个项目起的第一个名字。因为我们现在没有拿到商标，微信官方审核又变得特别严格，小程序名字必须要与公司名字相关，所以现在会看到一个有点奇怪的名字。（下面我还是以“找素食 App”来称呼这个项目）

关于公司名字的由来，在我们官网（huggypig.com）有介绍。

👉 我们公司是做素食的，为什么叫抱抱猪？

一些问题和思考​

产品定位​

简单来说，找素食 App 是一个集素食餐厅/商户搜索、素食食谱分享、社交及购物于一体的素食垂直平台，可以简单理解为是纯素版本的“大众点评 + 下厨房 + 东方甄选”。目标是解决素食人群在外面吃饭和在家做饭两大场景的痛点，并通过食品的高频消费形成商业闭环。未来还会推出 AI 营养师和烹饪助手，以及逐步发展自己的素食产品品牌，并探索“碳积分”等碳中和业务，助力 SDG 可持续发展目标。

我们希望打破素食者与非素食者的二元对立，我们希望打破素食者的刻板印象，我们希望帮助大家在素食这条路上吃饱、吃好、吃得更健康，我们希望可以赋能素食行业从业者，我们希望可以传播正确的文化价值观、实现 SDG 可持续发展目标。

用户群体​

我设想的用户群体是 plant-based 和 plant-forward 泛素食人群。也就是说包括严格意义上的素食主义者，以及只想多吃植物，但不完全排斥动物性食品的人群。这是我们认为世界应该有的样子，相对于只有极少数人坚持严格素食，我更希望看到未来每个人、每个家庭有50%（甚至更多）的餐饮选择是素食。

名字和商标​

关于这个 App 名字，我们之前征集过一次意见。我认真看了每个人给我的留言，虽然最终没有用上，但真的很感谢大家！

因为我喜欢简单、直接一点，所以我其实最想用的名字就是“找素食”。但是很遗憾，咨询了知识产权顾问，发现这种动词+名词的常用词组合很难注册成功（可以参考“下厨房”）。所以后来我又想了几个名字，包括“素托邦”等，并且提交了商标注册申请。

现在上架 App、小程序变得越来越严格，必须要有商标、著作权等认证，不是我们想用什么名字就能用。所以我现在的想法是，哪个商标能先拿到，我们就用哪个。在此之前，它还是叫“找素食”。

产品形态​

我们现在做的是微信小程序，选择先做小程序一方面是因为它的发布流程相比于原生 App 更简单，另一方面是我们目前没有搭建自己的独立电商平台，而是想依托于微信小店完成 MVP 功能验证，所以想先在微信生态中实现产品闭环。

只要项目能活下去，未来我们一定会做自己的独立电商、发布 Android 和 iOS 原生 App。如果用户需求强烈，我们也会考虑先发布一款阉割版的原生 App。

另外，考虑大家用网页越来越少，我们原本计划暂时不做 Web 网页版。但是由于微信小程序审核不通过等原因，我正在思考要不要先做一个网页版。或者在网页版上增加一些 to B 的功能，例如提供素食品牌和产品发布和查询功能。

市场规模​

素食目前还是一个小众赛道，我之前大概分析了目前素食领域做得比较好的一些平台、电商，头部企业年度 GMV 估计在五千万到一个亿。按食品行业 20% 的利润来说，一年能赚大几百万到一两千万。显然，和三只松鼠这些大众品牌相比，素食行业还有很大的发展空间。

研究市场和投融资这方面其实我也不太懂，这里就简单分享一下。

开放平台​

我们说要做一个开放、中立的平台，那怎么开放呢？

首先我们会持续收录素食品牌和产品、素食餐厅、素食食谱等信息资源，提供给大家查询（如果需要 API 服务，也可以私信我）。另外，我们发布的 HowToCookVegan 开源项目也是一种尝试，希望通过开源协作的方式和大家一起共创。

未来，如果有需求我们会考虑做一套餐厅订餐/点餐系统、农场管理系统，用开源 + SaaS 服务的方式给大家使用。我之前就有花一些时间调研餐厅、农场管理系统，发现其实已经有很多人在做，而且很多项目也已经死了。所以这些工作我们暂时还在规划中，需要多了解行业痛点，接收更多的抱怨声音，才知道应该做什么、怎么做。

合伙人​

我自己是从 2017 年开始尝试吃素的，从弹性素、锅边素开始，到后来蛋奶素、纯素、纯净素，体验了一遍，现在又回到了蛋奶素的状态。也是在这个过程中，我对素食行业有了更多了解，甚至打击邪教去了。打击邪教那段时间，我甚至极其厌恶“素食者”这个标签。后来有一次，我想通了！如果我真的喜欢素食这种生活方式，那我应该勇敢一点，直接参与商业竞争，把坏人赶走，告诉大家其实素食是这样的。于是就有了“找素食App”这个项目！

这两个月断断续续有一些人联系我，想了解这个项目，甚至想加入，所以我也在认真思考合伙人的问题。创业这条路真的太艰难、太孤独了，尤其对于“找素食 App”这个项目，我一个人忙不过，写代码的时候就没办法开拓市场。但是合适的合伙人可遇不可求，请神容易送神难，所以我的态度是宁缺毋滥。反正最坏的打算就是用我自己的钱，慢慢熬出来，目前我们公司的成本控制得不错，活个两三年问题不大。

所以如果你真的想加入，我希望你可以想清楚，准备好了和我一起战斗，不怕苦、不怕累、不怕邪恶势力，不要辜负这份事业，也不要辜负“联合创始人”的称号。

以上，祝大家新年快乐！我们 2026 年见~ 👋
